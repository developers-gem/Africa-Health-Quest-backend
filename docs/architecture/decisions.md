# Product & architecture decisions

| #   | Date       | Decision                                                                                                                                                                                                                                                            | Source                |
| --- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| D1  | 2026-11-03 | New GitHub repository (owner to connect); the Lovable-synced repo is not used for the rebuild.                                                                                                                                                                      | Product owner         |
| D2  | 2026-11-03 | Start fresh — no migration of Supabase users, progress or reviews. Mission **content** is still migrated verbatim.                                                                                                                                                  | Product owner         |
| D3  | 2026-11-03 | Guests play with a server-side guest account (expires after 30 days inactivity) that is upgraded **in place** to a full account, keeping progress.                                                                                                                  | Product owner         |
| D4  | 2026-11-03 | Missions are hidden from players until a clinician approves the current version.                                                                                                                                                                                    | Product owner         |
| D5  | 2026-11-03 | Only admins create/edit mission content for now (no separate author role).                                                                                                                                                                                          | Product owner         |
| D6  | 2026-11-03 | Monorepo with npm workspaces; npm 11 required (npm 10 has a peer-resolution bug with this tree).                                                                                                                                                                    | Engineering           |
| D7  | 2026-11-03 | Passwords hashed with Node's built-in scrypt (N=2^15) — no native dependency.                                                                                                                                                                                       | Engineering           |
| D8  | 2026-11-03 | Short-lived JWT access tokens (15 min) + opaque rotating refresh tokens stored hashed, with reuse detection. Web receives the refresh token as an httpOnly SameSite=Strict cookie; mobile receives it in the body for secure storage (`X-Client-Platform: mobile`). | Engineering           |
| D9  | 2026-11-03 | The authenticated user is re-loaded on every request so role changes/disabling take effect immediately.                                                                                                                                                             | Engineering           |
| D10 | 2026-11-03 | Registration is non-enumerating (always 202; the existing owner is emailed instead).                                                                                                                                                                                | Engineering           |
| D11 | 2026-11-03 | Container base image pulled from AWS ECR Public mirror of the official Node image (avoids Docker Hub anonymous rate limits).                                                                                                                                        | Engineering           |
| D12 | 2026-11-03 | Default AI model for debriefs: `claude-sonnet-5-5`, configurable.                                                                                                                                                                                                   | Engineering (Phase 4) |
